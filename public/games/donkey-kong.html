Donkey Kong

Wayne Westmoreland & Terry Gilman, 1982 · the original TRS-80 binary, emulated

Watch the code run

Controls

ENTER to begin, then 1 or 2 players. Shift and Home together clears the high scores.

About

Nintendo's Donkey Kong on a TRS-80, never sold.

Written purely because we liked it and played it so much. We could not get permission from Nintendo, so it was never marketed.

This is not a reimplementation. The original machine code is in the page and a Z80 runs it, so the game, its physics, its scoring and its sound are all the original, at the speed a real Model I ran them. The block graphics are exact; text is drawn from a 5x7 character generator, and choosing Model I also folds lowercase to capitals the way a machine without the lowercase mod did. High scores are kept in this browser. You can also watch the code run, one instruction at a time, with the disassembly beside it.
