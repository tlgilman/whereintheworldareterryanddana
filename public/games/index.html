TRS-80 ADVENTURES

Sixteen adventures lifted out of adams1 and adams2, each running on a JavaScript reimplementation of Scott Adams' 1979 interpreter.
Every one is a single self-contained file. Two-word commands. Type MAP to see where you have been; the game autosaves every turn.

Thirteen of these are the original Adams series, read straight off your disk images - the game data is byte-for-byte what the TRS-80 loaded.
The last three are third-party games written with the same engine: a James Bond adventure, and two by Bruce Hansen built with THE ADVENTURE SYSTEM.
Several of the later games are not treasure hunts and finish on an event rather than a score, so SCORE will simply count what you are carrying.
